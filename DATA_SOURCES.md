# Происхождение данных

## СберИндекс

Потребительские безналичные расходы на уровне муниципальных образований по
категориям трат. СберИндекс. Файл `consumption.parquet`, январь 2023 - декабрь
2024. Дата исходного скачивания неизвестна; локальная копия проверена
2026-10-07. Файл в первоначальном проекте побайтно совпал с файлом пользователя.

Источник, указанный в PDF поставщика:
https://sberindex.ru/ru/research/data-sense-opisanie-nabora-dannikh-khakatona-sberindeksa-po-munitsipalnim-dannim

Ссылка из ТЗ: https://www.sberbank.com/common/img/uploaded/files/pdf/sberindex/hackathonlicence.zip

SHA-256 consumption.parquet:
`9833ddaaee7b2a182ed4cceeed16469031700ea87d508bd976150c6770ef8a61`.

Индекс доступности рынков `market_access.parquet` относится к 2024 году по
описанию поставщика. Он сохранён для аудита, но исключён из нового эксперимента.
SHA-256: `434258afe322b7e6e6610b2552d129ae47094613de72dae3d13f6965a28d1dc1`.

Лицензия этих данных по приложенному описанию: CC BY-SA 4.0.
https://creativecommons.org/licenses/by-sa/4.0/

Справочник муниципалитетов:
https://sberindex.ru/ru/research/dataset-borders-and-changes-of-municipalities

Используется для стратификации выборки по региону. Географические координаты
последней версии справочника не включены в новый прогноз. Код региона не
меняется между версиями одного territory_id в предоставленном справочнике.

## Сообщения Банка России

В `data/external/cbr_rate_events.csv` сохранены восемь сообщений о повышении
ставки за 2023-2024 годы. URL, заголовки и точное время публикации проверены
по страницам Пресс-службы Банка России 2026-10-07. Источник каждого сообщения
записан в отдельной строке CSV. Сохраняется дата сегодняшней проверки.

Это ограниченная ретроспективная подборка сообщений, не полный новостной архив.
Декабрьский рост расходов не превращён в «новость». Изменение ставки измерено
в процентных пунктах, субъективные оценки влияния не используются.

## Методологические источники

- Prophet, работа с месячными данными:
  https://facebook.github.io/prophet/docs/non-daily_data.html
- Chronos и Chronos-Bolt, официальный код Amazon:
  https://github.com/amazon-science/chronos-forecasting
- Chronos-Bolt-tiny, карточка и веса:
  https://huggingface.co/amazon/chronos-bolt-tiny

У современных весов может быть период предобучения позднее проверяемых лет.
Отсутствие именно СберИндекса в предобучении независимо не установлено.
Поэтому результат Chronos обозначен как ретроспективный zero-shot тест.
