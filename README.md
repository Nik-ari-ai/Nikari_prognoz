# Прогноз потребления в муниципальных образованиях

Помесячный прогноз потребления по муниципальным образованиям (МО) на горизонты
1, 3, 6 и 12 месяцев, плюс мониторинг резких сдвигов потребления. Данные — СберИндекс.

## Задача

На уровне отдельных МО ряды короткие, шумные и сильно сезонные, поэтому единая
«средняя по стране» модель работает плохо. Мы сравниваем девять моделей на
одинаковых точках (111 МО, все категории) и отдельно проверяем, можно ли заранее
поймать структурный сдвиг потребления.

## Данные

Открытые данные СберИндекса (лицензия CC BY-SA 4.0), помесячно за 2023–2024 годы.
Лежат в `data/`: основной ряд `data/raw/consumption.parquet`, справочник МО,
внешние ряды ставки Банка России и ИПЦ Росстата. Происхождение — в `DATA_SOURCES.md`.

## Как запустить

Python 3.13, CPU. На macOS для LightGBM может понадобиться `brew install libomp`.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt -c environment.freeze.txt

python -m unittest discover -s tests         # 48 тестов
python scripts/21_forecast_unified.py        # главная таблица прогноза
python scripts/20_risk_seasonal.py           # мониторинг шоков
python scripts/16_build_manifest.py --check  # целостность, ожидается 0 несовпадений
```

Лендинг с итогами лежит в `outputs/landing/index.html`; пересобрать его можно
командой `python scripts/10_build_landing.py`.

## Результаты прогноза

Единая таблица по всем категориям (девять моделей: CatBoost, LightGBM, их ансамбль,
два варианта Prophet, ETS, Chronos-Bolt, сезонный наив), сравнение на общих ключах
111 МО. Выбор модели и его проверку мы разводим: стратегию выбираем только по ранним
отсечкам (2023-12, 2024-03, 2024-06), а поздний срез (2024-09, 2024-11) используем,
чтобы измерить этот выбор, не пересматривая его.

| Горизонт | Лучшая по бэктесту | Выбор по ранним данным | Проверка на позднем срезе |
|---|---|---|---|
| 1 мес | CatBoost (MAE 558.9) | Prophet (688.0) | 863.2, проиграл ансамблю (297.0) |
| 3 мес | ансамбль (483.1) | ансамбль (498.7) | 436.3, подтвердился |
| 6 мес | ансамбль (689.3) | ансамбль (689.3) | зрелых меток нет |
| 12 мес | Prophet (909.9) | Prophet (909.9) | зрелых меток нет |

Бустинги обгоняют базовый Prophet на горизонтах 1–6 месяцев, на 12 месяцах лучше
Prophet. Ни одна модель не выигрывает на всех горизонтах. На горизонте 1 месяц
ранний выбор на позднем срезе не подтвердился, и мы показываем это прямо, а не прячем.

## Мониторинг шоков

Шок определяется как отклонение МО от общего движения всех МО и от собственного
уровня. За счёт вычитания общего движения доля декабря среди событий падает с ≈98%
до 11.8%. Проверка — восемь непересекающихся фолдов плюс отдельный holdout, семь
методов при равном бюджете тревог, метрика PR-AUC с бутстрэп-интервалами.

Результат отрицательный и честный: сложные модели (CatBoost, LightGBM, логистическая)
не превосходят простое правило волатильности, а доверительные интервалы пересекаются.
Готовую систему раннего предупреждения на этих данных обосновать нельзя — сигнал слабый.

## Что доказано, а что нет

Доказано: воспроизводимый прогноз без утечек будущего, точнее базового Prophet на
горизонтах 1–6 месяцев; каузальный пайплайн; 48 тестов; проверка целостности
(`MANIFEST.json`, 0 несовпадений).

Не доказано: раннее предупреждение о шоках (отрицательный результат). Нет независимого
нового года для финального теста — ретроспективное разбиение уже просмотренных данных
им не является.

## Структура репозитория

- `scripts/` — пайплайн по шагам: загрузка, признаки, бэктест, прогноз, детекторы.
- `src/` — модули: данные, признаки, модели, бэктест, разметка шоков.
- `reports/` — методология, scorecard по критериям жюри, реестр ограничений.
- `outputs/` — посчитанные метрики, прогнозы, лендинг.
- `data/` — исходные данные.
- `tests/` — тесты временной безопасности.

Код в `evidence/original/` — исходная версия проекта до аудита, оставлена без
изменений для сравнения.
